# Digital Image Processing Codes

This repository contains implementations of Digital Image Processing (DIP) lab experiments.

## 📌 Topics Covered
- Image Enhancement (Histogram, Filtering)
- Edge Detection (Sobel, Prewitt, Canny)
- Image Transformation (Scaling, Rotation)
- Morphological Operations
- Image Segmentation
- Feature Extraction (GLCM, LBP)

## 🛠 Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib

## 📂 Folder Structure
Lab1/
Lab2/
Lab3/
...
Each folder contains code and output for respective experiments.

## ▶️ How to Run
1. Install dependencies:
   pip install opencv-python numpy matplotlib

2. Run any file:
   python filename.py

## 📸 Output
Each lab includes sample outputs and visual results.

## 🎯 Purpose
This repo is created for academic learning and practical understanding of DIP concepts.
